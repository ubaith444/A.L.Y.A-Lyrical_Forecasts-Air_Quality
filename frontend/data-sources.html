Data Provenance & System Integrity

Meteorological Data Sources Registry

The Tamil Nadu Climate & Forecast Intelligence Platform integrates 5 distinct meteorological and climatological providers. This registry provides full transparency on data origin, sampling methodology, update cadence, latency, and operational boundaries.

Environment: Production Persisted
Storage Root: /var/data
Database: SQLite + Parquet Datasets
Operational Scope & Scientific Limitations
  • Data Integrity: The platform and weather map use actual provider responses for the 15 configured canonical monitoring locations. These represent city-centre points, not district-wide areal averages. No synthetic sample weather values or seeded alert records are used.
  • Authoritative Warning Notice: Generated notifications and risk indices are automated heuristic indicators designed for operational planning, not official meteorological warnings. Official weather warnings, cyclone alerts, and synoptic bulletins issued by the India Meteorological Department (IMD) / RMC Chennai strictly take legal and operational precedence.
  • Spatial Representation: The Tamil Nadu map is geographically interactive with real telemetry layers, but currently displays point-centric choropleth boundaries rather than survey-accurate cadastre polygon boundaries.

Data Storage & Persistence Policy

1. Persistent SQLite Database

Stored on persistent mounted storage (/var/data/climate_forecast.db). Tracks 38 district records, heuristic risk alerts, operator acknowledgements, settings changes, and audit logs. Never lost across service restarts or container redeployments.

2. Parquet Datasets

Historical weather observations and chronological validation records stored in compressed Apache Parquet format (/var/data/datasets/*.parquet) for columnar scan performance and zero memory bloat.

3. Model Artifacts

Trained baseline ML weights (XGBoost, LightGBM, Random Forest, Ridge regression) and scalers saved as serialized joblib binaries (/var/data/models/) with chronological leak-free cross-validation guarantees.
